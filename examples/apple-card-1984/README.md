# Apple-Inspired Credit Card Banking Design System + 1984 Video

This is a demo of **ATV Design**: the design system and 1984-inspired animation are presented as outputs built with the ATV Design tool.

This example contains:

- `DESIGN.md` — Aperture Card OS, a credit card banking design system inspired by Apple-like restraint and 1984 Macintosh-era motion language.
- `tokens.json` — machine-readable design tokens for colors, typography, spacing, radius, stroke, and motion.
- `index.html` — a HyperFrames animated video composition with CRT scanlines, window shutters, card UI choreography, and banking/security scenes.

Not affiliated with or endorsed by Apple Inc.; no Apple logos, proprietary icons, or copied screens are used.

## Commands

From this folder:

```bash
pnpm run check
pnpm run render
```

Or from the repository root:

```bash
pnpm --dir examples/apple-card-1984 run check
pnpm --dir examples/apple-card-1984 run render
```
