# skills/ui-ux-pro-max

This directory preserves the additive `ui-ux-pro-max` source bundle for ATV Design.

The runtime loader remains flat and non-recursive, so the shipped runtime entrypoints live under `packages/core/src/skills/builtin/uipromax-*.md`.

This preserved bundle keeps the upstream source material, support data, scripts, templates, references, and font assets in-repo for provenance and local lookup.
